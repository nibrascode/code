О приложении Nibras Nova

Nibras Nova — браузер для Android с блокировкой рекламы и трекеров, режимом «только HTTPS», приватным режимом, биометрическим хранилищем, режимом чтения, RSS и 5 языками. Без аккаунта, рекламы и слежки. Приложение в разработке; все функции — на nibrascode.com/nibrasnova.

Безопасный контент

Безопасность семьи: сайты для взрослых (18+) всегда блокируются, в Google, Bing, DuckDuckGo и YouTube принудительно включён безопасный поиск. Проверка выполняется полностью на устройстве по встроенному списку (StevenBlack/hosts, MIT); данные о просмотре никуда не отправляются. Работает и в приватных вкладках.

🆕 Что нового

Новое: время намаза с обратным отсчётом на главной (расчёт на устройстве, выбор метода), дата по хиджре, карточки «Интересное», резервная копия закладок и истории в JSON (экспорт/импорт) и импорт закладок HTML, меню по долгому нажатию на ссылку (открыть, копировать, поделиться) и исправленный режим ПК-версии.

Конфиденциальность и данные

🔒

Кратко

Nibras Nova — веб-браузер от Nibras Code. В нём нет учётных записей, рекламы, аналитики и SDK для отчётов о сбоях. Всё, что вы создаёте в приложении (история, закладки, вкладки, настройки, заметки, содержимое хранилища), хранится только на вашем устройстве. Мы, разработчик, не получаем и не храним ваши данные.

🔒

Данные на вашем устройстве

• История, закладки, открытые вкладки, быстрые ссылки, список загрузок, RSS-ленты, отслеживаемые страницы, заметки/выделения, пользовательские скрипты и настройки (в локальной базе данных и настройках приложения). • Просмотр в приватных вкладках не записывается в историю. • Элементы хранилища и резервные копии шифруются (AES-256) ключом или паролем, который остаётся на устройстве. • Облачное резервное копирование Android для данных приложения отключено; данные покидают устройство, только если вы сами их экспортируете (HTML-экспорт закладок, зашифрованная копия, передача по Wi-Fi). • Вы можете удалить всё в любой момент: очистить историю, использовать «Экстренную очистку» или удалить приложение.

🔒

Сетевые подключения

• Открываемые сайты: устройство подключается к ним напрямую, как в любом браузере. У этих сайтов свои политики конфиденциальности. • Поиск: текст из адресной строки отправляется в выбранную поисковую систему (по умолчанию DuckDuckGo; также Google, Bing, Brave, Startpage или своя). • Безопасный DNS (по желанию): если включить DNS-over-HTTPS, запросы доменов идут выбранному провайдеру (Cloudflare, Quad9 или AdGuard). Если задать прокси, трафик идёт через него. • Перевод страницы: «Перевести страницу» открывает её через Google Translate (translate.google.com), который получает адрес страницы. Перевод текста выполняется на устройстве с помощью Google ML Kit; языковые модели один раз скачиваются у Google, а сам текст переводится на устройстве. • Безопасный просмотр: Android System WebView может проверять адреса через Google Safe Browsing, чтобы предупреждать об опасных сайтах. • RSS-ленты и отслеживание страниц обращаются только к добавленным вами адресам. • Передача по Wi-Fi запускает временный сервер только в вашей локальной сети и только пока открыт экран передачи; через интернет ничего не идёт.

🔒

Разрешения

• Интернет / состояние сети: для загрузки страниц. • Камера: только для сканирования QR-кодов и когда сайт запрашивает камеру (сначала спрашиваем вас). • Микрофон: только когда сайт его запрашивает, например для видеозвонка (сначала спрашиваем вас). • Местоположение: только когда сайт запрашивает его (сначала спрашиваем вас). Само приложение местоположение не собирает. • Уведомления: для прогресса загрузок и оповещений об изменениях страниц. • Биометрия: для открытия хранилища и приватных вкладок; данные отпечатка/лица не покидают защищённое оборудование Android. • Хранилище (только старые версии Android): для сохранения загруженных файлов. • Состояние Wi-Fi: чтобы показать локальный адрес для передачи по Wi-Fi.
