# nibras-xray

**3D Code X-Ray** — see a codebase's structure and problem spots as a 3D map, entirely in the browser. Code is never uploaded.

- Live: https://nibrascode.com/xray
- Part of [Nibras Code](https://nibrascode.com) developer tools (Studio IDE: https://dev.nibrascode.com, APK Studio: https://studio.nibrascode.com)

## What it shows
- Files and modules as nodes, imports as links
- Size / complexity hot spots
- Runs client-side (no server analysis)
