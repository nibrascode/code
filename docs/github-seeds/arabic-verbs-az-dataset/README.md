# arabic-verbs-az-dataset

Arabic verbs with **Azerbaijani** translations — past (الماضي), present (المضارع) and imperative (الأمر) forms, root and transliteration.
Prepared by [Nibras Code](https://nibrascode.com) from the word base of the **Nibras Arabic** app.

- App (Android, offline, free): https://nibrascode.com/apps/nibras-arabic
- Google Play: https://play.google.com/store/apps/details?id=com.nibrasarabic.app

## Format (planned)
```csv
root,past,present,imperative,translit_past,az
كتب,كَتَبَ,يَكْتُبُ,اُكْتُبْ,kataba,yazmaq
```
